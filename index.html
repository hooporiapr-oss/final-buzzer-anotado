Three steps, and then every game after it.

BEFORE THE GAME

Padrinos pledge on the game

The program shares the game. Each padrino promises a few cents for every point the team scores in it.

GAME DAY

The team plays its game

It plays its game the way it was already going to. The score goes in at the scoreboard and nothing else has to be entered.

WHEN THE SCORE POSTS

Padrinos get the score. The program gets paid.

Each padrino gets one email with the final score and what their pledge came to, and a link to pay the program directly. The money never passes through us.

What it costs

Five dollars a game. Only the games you put pledges on.

You pick which games on your schedule carry pledges — a program signs up for five to start, and there is no ceiling. Each game that records pledges is five dollars; each game that records none is nothing. The report is yours to print the moment a game closes, and the invoice comes after that.

Each game you put pledges on $5

The same five dollars whatever the game is — a round-robin game, a bracket game, a league game. It does not move with your roster, with how much you raise, or with how many padrinos a game brings in.

  • Nothing up front. Signing up is free and running it is free.
  • No pledges, no fee. A game that records no pledges is never invoiced — not at five dollars, not at anything.
  • Invoiced for the games that carried pledges, due within seven days.
  • Not a percentage of anything. It does not come out of any pledge, and your padrinos are charged nothing.
  • If it is not paid, that licence lapses and its pledge data comes off the platform. We do not chase it any further.
